## 🇫🇷 Français

Cliquez ci-dessous pour ouvrir un éditeur Lean prêt à l'emploi dans votre navigateur.
Aucune installation requise. Un compte GitHub (gratuit) est nécessaire.

[![Ouvrir dans Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/christian-chavez/mat120-Lean)

**Première fois :** la configuration prend environ 15 minutes — cela n'arrive qu'une seule fois.
Ensuite, il suffit de rouvrir le même Codespace : ça démarre en quelques secondes.

Une fois ouvert, consultez `MAT120/Welcome.lean` pour commencer.

**Si je pousse des mises à jour :** dans le terminal de votre Codespace, tapez `git pull` pour les récupérer.

**Important :** si vous n'utilisez pas votre Codespace pendant 30 jours, il sera automatiquement supprimé.
Ouvrez-le au moins une fois par mois pour éviter cela (même juste quelques secondes suffisent à réinitialiser le délai).
Si cela arrive quand même, pas de panique : il suffit de recréer un nouveau Codespace avec le lien ci-dessus (~15 minutes, une seule fois).

## 🇬🇧 English

Click below to open a ready-to-use Lean editor in your browser.
No installation needed. You'll need a (free) GitHub account.

[![Open in Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/christian-chavez/mat120-Lean)

**First time:** setup takes about 15 minutes — this only happens once.
After that, just reopen the same Codespace and it starts in seconds.

Once it opens, look at `MAT120/Welcome.lean` to get started.

**If I push updates:** run `git pull` in your Codespace terminal to get them.

**Important:** if your Codespace goes unused for 30 days, it will be automatically deleted.
Open it at least once a month to avoid this (even just a few seconds resets the countdown).
If it does happen, no worries — just recreate a new Codespace with the link above (~15 min, one time).
